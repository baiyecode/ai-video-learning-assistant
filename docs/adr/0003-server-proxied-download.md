# Download 由服务端代理并以临时文件交付

Download 统一由服务端执行 yt-dlp 下载与 ffmpeg 合并，完成后通过 15 分钟有效的签名 URL 交付，支持 Range 断点续传；文件最多保留 1 小时，单文件上限 2GB。不把平台直链作为主要交付方式，因为平台直链有时效签名与防盗链，用户拿到后未必可用，也无法统计与限流。

**考虑过的替代方案**：直接返回平台直链（成本最低但不可控）；对象存储 + 预签名 URL（更易扩展，但为 MVP 增加一个外部依赖）。

**Consequences**：服务端承担带宽与磁盘成本，需要定时清理任务；多实例部署前必须先把文件存储外置。
